# 05 · Interfaz

Pedida por el usuario: herramienta profesional, **modo oscuro, densidad de información y usabilidad**, alejada del diseño web tradicional. Referencias: shadcn/ui (componentes) y Quixel Mixer (flujo). En el brainstorming eligió la distribución **A (pila de capas + inspector)** como vista principal, con el **grafo de nodos** como vista avanzada.

## Vista principal

```
┌ barra: Archivo Editar Vista IA · proyecto ·············· [Preview 1K] [Render final] [Exportar] ┐
├ Material ─────┬ Atlas 2D ─────────────┬ Vista 3D ──────────────┬ Inspector ──────────────────────┤
│ set PBR       │ mapa activo           │ forma de prueba        │ parámetros de la capa           │
│ Pila          │ rects superpuestos    │ HDRI, luz              │ seleccionada, por secciones     │
│  Layout       │ selección de rect     │ modos: lit / mapa /    │ plegables, valores numéricos    │
│  Estructura   │ zoom 1:1, tiling      │ wireframe de rects     │ editables con unidades          │
│  Daño         │                       │                        │                                 │
│  Suciedad     │                       │                        │                                 │
│  IA           │                       │                        │                                 │
│ Comprobaciones│                       │                        │                                 │
├───────────────┴ BaseColor Normal Height Rough Metal AO Desgaste IDs ··· 4096² · 512 px/m · GPU 41 ms ┤
```

- Los paneles se pueden redimensionar, plegar y maximizar (por ejemplo, la vista 3D a pantalla completa). La distribución se recuerda.
- **Atlas 2D**: zoom y desplazamiento, vista 1:1, modo tiling (para ver cómo se repite una franja), superposición de rectángulos con sus metros, de la rejilla de periodo del material y de los fallos de comprobación. Al seleccionar un rectángulo se ven y editan sus propiedades en el inspector.
- **Vista 3D**: formas de prueba (cubo, pared con huecos, pasillo, columna, escalera) a las que se aplica el hotspot automáticamente con el mismo criterio de encaje que usan las herramientas de destino: mejor rectángulo por proporción y tamaño, rotación y espejo según los flags. Usa HDRIs incluidos, luz direccional móvil, vistas de mapa sueltas y la opción de filtrado point para revisar pixel art.
- **Inspector**: sliders compactos con campo numérico. Arrastrar sobre la etiqueta cambia el valor, se aceptan unidades (cm, mm, m) y expresiones simples, doble clic restablece el valor por defecto y cada parámetro tiene un tooltip.
- **Estructura** (v0.1, sección del inspector): tipo propuesto (Piezas, Continuo, Direccional) con el número de piezas, campo de umbral (muestra el sugerido mientras es automático, vacío si no hay juntas) y botón Detectar, que vuelve a analizar y aplica el periodo detectado aunque el usuario lo hubiera cambiado. La barra de mapas tiene la pestaña **Piezas**, que colorea el atlas por ID de pieza con el mismo hash que IDs rect.
- **Desgaste** (v0.1, sección del inspector): familia (propuesta al importar y al analizar con `proposeFamily`; si el usuario elige una, se marca `userSetFamily` y ya no se propone), intensidad, alcance (cm), borde mínimo (mm), tamaño de rotura (cm), profundidad (mm), banda de fractura (mm), microdetalle (mm), "Sigue las piezas", tono de canto y semilla con botón ⟳. La máscara B/N se importa como imagen (negro quita el daño salvo el borde mínimo, gris medio es neutro y blanco lo duplica) y tiene fuerza e invertir. El sustrato elige el origen (Interior o Segundo material, que se importa con la misma clasificación de mapas; solo se suben BaseColor, Roughness, Metallic y AO, que son los que lee la pasada de color) y el tono (±180°), la saturación, el valor y la rugosidad del interior, que se desactivan mientras hay un segundo material cargado. Con un segundo material cargado aparece "Tamaño (m)" (X e Y), el tamaño real de una repetición: el segundo material respeta la regla de proporciones igual que el de arriba. Volver a importar el mismo set (mismo nombre) conserva ese tamaño; otro set empieza en 1 × 1 m. Si se reemplaza el material mientras se importa una máscara o un segundo material, esa importación se descarta con un aviso. Los campos guardan metros y muestran cm o mm. Cada campo tiene un tooltip en español. La barra de mapas tiene la pestaña **Desgaste**, que muestra el `wearMask`.
- **Suciedad** (v0.1, sección del inspector): cavidad, escorrentía, longitud (cm) y tinte (selector de color).
- La máscara y el segundo material viven solo en el estado de la app: el documento aún no guarda imágenes, así que no se guardan con el proyecto. Reemplazar el material los quita.
- Los cambios del inspector recomponen el atlas sin repetir el análisis de estructura. Las recomposiciones se agrupan (150 ms) y nunca se apilan: si llega un cambio mientras se compone, se compone una vez más al terminar.
- **Comprobaciones**: siempre visibles, con estado (ok / aviso / error). Al hacer clic se lleva la vista al problema.
- Deshacer/rehacer ilimitado sobre el grafo. Atajos de teclado para todo lo habitual, con una paleta de comandos (`Ctrl+K`).
- Barra de estado con resolución, densidad, tiempo de GPU, VRAM usada y estado del sidecar de IA.

## Vista de nodos

- El mismo documento mostrado como grafo (React Flow). Inspector a la derecha y vistas 2D/3D abajo.
- Cada nodo tiene una miniatura de su salida. Se puede "ver este nodo" en el atlas y en el 3D.
- Incluye los nodos que la pila no ofrece: mezclas arbitrarias, máscaras combinadas, operaciones de canal, ruidos, ramas por grupo de rectángulos.
- Se cambia entre pila y nodos sin perder nada (ver [02-architecture.md](02-architecture.md)).

## Estilo visual

- Paleta neutra oscura (gama zinc), un único color de acento para la selección y el estado activo, y verde, ámbar y rojo solo para el estado de las comprobaciones.
- Tipografía pequeña (11–12 px) en paneles, cifras tabulares y alto contraste en el texto principal.
- Nada de tarjetas grandes, sombras decorativas ni espacios vacíos de landing page. Cada píxel de panel muestra información o un control.
- Idioma de la interfaz: el constructor elige la estructura i18n. Arranca en inglés y español, con el español primero para el equipo.
